# Diseño de camara de refrigeracion y sistema de aire acondicionado
Para este proyecto se diseño un sistema de refrigeracion de dos etapas para refrigerar un flujo de producto de 1 000 kg/h de camarones a una temperatura de-20 °C usando refrigerante R717 . Además, se debía reaprovechar el calor de la segunda etapa para implementar un sistema de aire acondicionado para una oficina. En base a este enunciado, se investigaron y asumieron supuestos fundamentados bibliográficamente y se hicieron los cálculos
respectivos tanto para obtener las cargas térmicas de la cámara de refrigeración y de la oficina.

### Calculos
Los diametros internos calculados para las diferentes secciones de la tuberia del sistema de refrigeracion R-717 son los siguientes:
 
 * Linea de Succion del Evaporador de Baja: 268,6 mm
 * Linea de Succion del Evaporador de Alta: 7,57 mm
 * Linea de Descarga del Compresor de Alta: 31,04 mm
 * Linea de Liquido al Evaporador de Alta: 2,08 mm
 * Linea de Liquido al Evaporador de Baja: 10,39 mm
 * Linea de Descarga del Compresor de Baja: 36,48 mm

<br>
Finalmente tras realizar los calculos se obtuvo un COP de 3.501
